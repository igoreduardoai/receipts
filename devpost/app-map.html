🧾 Receipts — App Map

Receipts checks each sentence of an AI answer against pasted sources and stamps it Supported, Partial, No receipt, Number mismatch or Negation flip. Three pieces: the page (index.html + src/styles.css), the UI wiring (src/app.js), and the engine (src/engine.js). No server, no external services; the only storage is the browser's localStorage key receipts:v1.

One action, end to end: “Check receipts”

Click
button #check in index.html
→
run()
src/app.js reads both boxes, saves to localStorage
→
checkAnswer()
src/engine.js: buildIndex → bestMatches → verdictFor
→
render() / showEvidence()
stamps, score, highlighted receipt

Reference route (3 stops)

  1. src/app.js → search function run(): validates input, calls checkAnswer, then render().
  2. src/engine.js → search export function bestMatches: scores every passage by IDF-weighted coverage(), BM25 as tiebreak; adjacent-sentence pairs only win if they add 10+ points of coverage.
  3. src/engine.js → search export function verdictFor: thresholds from THRESHOLDS, then the number (extractNumbers) and negation (hasNegation) overrides.

This is a reference route; it was not toured live with the learner.

To change this, start here

Make the checker stricter or looser

THRESHOLDS at the top of src/engine.js (Supported 0.6, Partial 0.35). Run npm test after.

Teach it a synonym

Add an entry to the CANON map in src/engine.js (stemmed word → shared term).

Change stamp wording or colors

Labels/icons: VERDICTS in src/engine.js. Colors: .v-supported … .v-short in src/styles.css.

Change the sample

src/sample.js — then update the expected stamps in tests/engine.test.js.

A practice to reuse

Test with a second, unrelated input before trusting the first. The sample passed on the first try, but a bike-share example (tests/engine.test.js → “document title words count as context”) exposed two real gaps — synonyms hiding a number change and title words being ignored — recorded in devpost/checklist.md > Revisions. The same move works on any rule-based or AI feature: keep one regression test from a case you did not design for.

Run it again

npm start → open http://localhost:5173 → Load sample → Check receipts. npm test runs the engine suite.
